---
name: context-tool-use
description: Use YourAI for private context missing from general knowledge or this conversation.
---

Use YourAI before asking for clarification when a request may depend on organization knowledge or the user's recent computer activity.

- Search organization knowledge for shared people, clients, systems, terms, facts, or procedures.
- Search recent computer activity for personal context the user recently viewed or worked on.
- If the tools are deferred, search the available tools for `yourai-context`, then call the relevant tool.
